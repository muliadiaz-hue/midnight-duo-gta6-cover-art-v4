Midnight Duo turns your own photos into a GTA 6-style cover: a band layout (hero + 2×2 panels), six layouts, six colour grades with a photographic default, a one-line "MIDNIGHT DUO" title in Passion One with a sunset gradient and ink outline, city "AZURA BAY", tagline "TWO LEADS · ONE SCORE", sash "ONE NIGHT ONLY", per-panel captions, undo/redo, drag-pan + wheel-zoom, deterministic grain — and one-click PNG export in four post sizes (1080×1080, 1080×1350, 1920×1080, 1080×1920). Fully offline, vanilla JS + Canvas 2D, no network requests, no Rockstar artwork or fonts.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
